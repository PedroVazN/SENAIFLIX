Aplicação de console em Java que simula a contratação de um serviço de streaming de filmes e séries.

## Sobre o projeto

Aplicação de console em Java que simula a contratação de um serviço de streaming de filmes e séries.

## Conteúdo

- Seleção de gêneros e títulos
- Cadastro de um novo filme
- Escolha de plano de assinatura
- Seleção da forma de pagamento
- Cálculo e exibição do valor final

## Tecnologias

- Java

## Organização do repositório

Os dois arquivos Java representam versões da aplicação. A imagem `SENAIFLIX.png` apresenta a identidade visual do projeto.

## Como visualizar ou executar

```bash
git clone https://github.com/PedroVazN/SENAIFLIX.git
cd SENAIFLIX
javac Senaiflix.java
java Senaiflix
```

O repositório também contém a variação `SenaiflixDeluxe.java`.
